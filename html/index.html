Cara mengajukan cuti / izin
Buka menu Pengajuan, pilih tab Cuti.
Pilih Jenis: Cuti Tahunan, Sakit, Izin, atau Cuti Tanpa Gaji.
Tentukan Tanggal Mulai dan Tanggal Selesai.
Tulis Alasan dengan jelas. Untuk jenis Sakit, lampiran surat keterangan wajib diisi.
Ketuk Kirim Pengajuan. Status awal selalu Menunggu.
Pantau hasilnya di Riwayat Pengajuan di bawah formulir.
Arti statusMenunggu = belum diproses admin. Disetujui = pengajuan diterima. Ditolak = tidak diterima; baca catatan admin pada kartu.
Panduan pengisian tiap jenis pengajuan
TabField yang diisiCatatan penting
Cuti & Izin Jenis, Tanggal Mulai, Tanggal Selesai, Alasan, Lampiran (opsional). Jenis Sakit wajib melampirkan surat keterangan sakit. Cuti tahunan memotong sisa kuota cuti.
Lembur Tanggal Lembur, Jam Mulai, Jam Selesai, Alasan Lembur. Isi jam aktual lembur. Durasi dihitung otomatis dari selisih jam.
Koreksi Jenis Koreksi, Tanggal Absensi, Jam Masuk/Pulang yang diajukan, Alasan, Lampiran. Pilih Telat / Dispensasi untuk mengoreksi jam masuk, atau Lupa Absen Pulang untuk jam pulang.
Kasbon Jumlah Kasbon, Cicilan per Bulan, Tanggal Kasbon, Alasan Kasbon. Cicilan harus lebih dari 0 dan tidak boleh melebihi jumlah kasbon. Saldo dipotong pada slip gaji.
Perhatikan validasiSistem menolak pengiriman jika tanggal, jam, atau alasan belum lengkap. Untuk kasbon, cicilan harus lebih kecil atau sama dengan total kasbon.
Setelah dikirimPengajuan tidak dapat diubah dari aplikasi. Jika salah, hubungi admin agar diproses (disetujui/ditolak) lalu buat pengajuan baru bila perlu.

Pertanyaan yang sering muncul

Solusi cepat untuk kendala yang paling sering terjadi saat operasional.

Kenapa aplikasi tiba-tiba kembali ke halaman login?

Sesi login sudah berakhir atau token tidak lagi valid. Aplikasi otomatis keluar dan menampilkan pesan "Sesi Anda telah berakhir. Silakan login kembali." Masuk lagi dengan username dan password Anda. Jika sering terjadi, hubungi admin untuk memeriksa konfigurasi server.

Tombol Absen Masuk tidak bisa ditekan atau absen ditolak?

Periksa tiga hal: izin lokasi sudah aktif, GPS dalam keadaan hidup, dan Anda berada di dalam radius toko. Pastikan juga Anda belum melakukan absen masuk hari ini. Jika masih gagal, minta admin melakukan koreksi absensi.

Lokasi tidak terdeteksi di aplikasi mobile?

Aktifkan GPS dan izin lokasi untuk aplikasi Zea HR. Keluar sebentar dari aplikasi lalu buka kembali, atau nyalakan lalu matikan mode pesawat. Di dalam gedung, mendekat ke jendela dapat membantu sinyal GPS.

Pengajuan sudah dikirim, tapi statusnya masih Menunggu?

Pengajuan menunggu diproses admin di Pusat Approval. Pantau status pada daftar Riwayat Pengajuan di aplikasi. Jika sudah lama, hubungi admin. Status akan berubah menjadi Disetujui atau Ditolak beserta catatan admin.

Kenapa slip gaji periode ini belum muncul di aplikasi?

Slip hanya muncul setelah admin menekan Finalisasi pada payroll periode tersebut. Jika periode sudah lewat tetapi slip tetap tidak ada, hubungi admin untuk memastikan payroll sudah difinalisasi.

Generate payroll gagal atau diblokir?

Artinya masih ada pengajuan pada periode tersebut yang belum diproses. Buka Pusat Approval dan selesaikan seluruh pengajuan cuti, lembur, koreksi, dan kasbon, lalu generate payroll kembali.

Bagaimana gaji harian atau mingguan dihitung?

Tipe penggajian diatur admin di Master Karyawan. Untuk tipe harian, gaji pokok = nominal harian x hari terbayar. Untuk tipe mingguan, gaji pokok = nominal mingguan / jumlah hari kerja per minggu x hari terbayar. Hari terbayar mencakup hadir, telat, sakit, cuti tahunan, dan dinas luar. Tipe bulanan dibayar penuh per periode, lalu alpha dan cuti tanpa gaji dipotong. Uang makan dan transport selalu dihitung dari jumlah hari hadir.

Lupa password akun Zea HR?

Password dikelola oleh admin melalui Manajemen User di web. Hubungi admin untuk melakukan reset password. Karyawan tidak dapat mengubah password sendiri dari aplikasi mobile.

Apakah bisa absen dari luar area toko?

Tidak. Absensi divalidasi dengan geofence. Jika jarak HP melebihi radius yang diatur admin, absensi akan ditolak. Pastikan Anda berada di area toko saat melakukan absen masuk maupun pulang.
